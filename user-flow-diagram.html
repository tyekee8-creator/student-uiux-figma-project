Flow Summary
Main path: Open App → Login/Register → Home → Browse → Restaurant Menu → Add to Cart → Cart → Checkout → Payment → Order Confirmed → Tracking → Delivered
Auth branch: Returning users → Login · New users → Register
Order branch: Add more items → back to menu · Done → Cart
Payment branch: Success → Confirmation · Failure → Error + Retry
