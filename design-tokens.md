# QuickBite Design Tokens

## Colors
| Token | Value | Usage |
|-------|-------|-------|
| `--color-primary` | `#FF4B2B` | CTAs, active states, brand |
| `--color-primary-2` | `#FF416C` | Gradient end |
| `--color-bg` | `#FAFAF8` | Page background |
| `--color-surface` | `#FFFFFF` | Cards, modals |
| `--color-text` | `#1A1A2E` | Body text |
| `--color-text-muted` | `#6B7280` | Secondary text |
| `--color-success` | `#2ECC71` | Confirmations |
| `--color-border` | `#E5E7EB` | Dividers, card borders |
